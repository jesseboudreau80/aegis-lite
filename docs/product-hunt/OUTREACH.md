**Dev.to / Hashnode / Substack cross-post pitch (for blog post):**
Write a companion post titled: **"I built an AI governance layer and open-sourced it — here's why and how"**

Structure:
1. The problem (the governance gap in every AI deployment)
2. Why existing tools don't solve it (vendor-locked, not auditable)
3. How the policy engine works (deterministic, rule trace, risk score)
4. The architecture (policy-before-inference vs. alongside)
5. What's in the repo (feature table)
6. How to contribute (issue list, policy rule guide)
7. What's next (roadmap)

This post drives search traffic and GitHub stars long after PH day fades.
